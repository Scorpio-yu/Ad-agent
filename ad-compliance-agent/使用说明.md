# 广告合规审核工具 — 使用说明

## 这是什么？

一个帮你检查广告文案是否违规的 AI 工具。输入广告文字，AI 会判断是否违反广告法，并给出修改建议。

---

## 第一步：安装 Python（如果已有，跳过）

1. 打开 https://www.python.org/downloads/
2. 点击黄色按钮 "Download Python"，下载后双击安装
3. ⚠️ **安装时一定要勾选底部的「Add Python to PATH」**（把 Python 加到系统路径）
4. 一直点 Next 直到完成

验证是否装好：按 `Win+R`，输入 `cmd`，回车，输入 `python --version`，如果显示版本号就是装好了。

---

## 第二步：安装本项目（只需做一次）

1. 双击 `setup.bat`
2. 等待它跑完（大概 2-5 分钟，视网速而定）
3. 看到「Setup complete!」就完成了

---

## 第三步：配置 API Key（只需做一次）

打开 `.env` 文件（记事本即可），修改下面两行：

```
OPENAI_API_KEY=sk-你的DeepSeek-Key
EMBEDDING_API_KEY=sk-你的SiliconFlow-Key
```

### 怎么获取这两个 Key？

| Key | 去哪里申请 | 费用 |
|-----|-----------|------|
| DeepSeek | 打开 https://platform.deepseek.com 注册，在「API Keys」页面创建 | 充值 10 块够用很久 |
| SiliconFlow | 打开 https://siliconflow.cn 注册，在「API 密钥」页面创建 | 新用户送免费额度 |

> 💡 为什么需要两个？DeepSeek 负责"理解广告文字"，SiliconFlow 负责"检索法规条文"。各有分工。

---

## 第四步：启动

双击 `启动.bat`，看到 "Application startup complete" 后，打开浏览器输入：

```
http://localhost:8000
```

在输入框里输入广告文案，点发送，等待几秒就能看到审核结果。

---

## 日常使用

以后每次用只需做：
1. 双击 `启动.bat`
2. 打开浏览器访问 http://localhost:8000

不用再跑 setup。

---

## 停止

在启动的黑窗口里按 `Ctrl+C` 即可停止，或者直接关掉窗口。

---

## 如果出问题

| 现象 | 解决 |
|------|------|
| 双击 setup.bat 闪退 | 先装 Python（见第一步） |
| setup.bat 提示网络错误 | 检查网络，或者把 pip 源换成国内镜像 |
| 启动后浏览器打不开 | 确认黑窗口里没有错误信息，试试 http://127.0.0.1:8000 |
| API 调用报错 | 检查 `.env` 里的 Key 是否填写正确 |
