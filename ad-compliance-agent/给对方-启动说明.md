# 广告合规审核 Agent — 启动说明

## 你需要准备
- **Docker Desktop**（https://www.docker.com/products/docker-desktop/）
- **DeepSeek API Key**（platform.deepseek.com 注册获取）
- **SiliconFlow API Key**（siliconflow.cn 免费注册，用于 embedding）

## 启动（3 步）

### 1. 加载镜像
打开终端（PowerShell），进入本文件夹：
```
docker load -i ad-compliance-agent.tar
```

### 2. 配置 Key
```
copy .env.example .env
```
用记事本打开 `.env`，改 2 个 Key：
```
OPENAI_API_KEY=sk-你的DeepSeek-Key
EMBEDDING_API_KEY=sk-你的SiliconFlow-Key
```

### 3. 启动
```
docker compose up
```

浏览器打开 **http://localhost:8000**，输入广告文案即可审核。

## 停止
按 Ctrl+C，或者再开一个终端运行：
```
docker compose down
```

## 常见问题

**Q: 为什么需要两个 Key？**
DeepSeek 只有对话模型，没有 embedding（向量化）接口。Embedding 用 SiliconFlow 的免费额度。两个 Key 都在 siliconflow.cn 免费注册。

**Q: 我想用自己的 OpenAI Key？**
编辑 `.env`：
```
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_MODEL=text-embedding-3-small
EMBEDDING_API_KEY=sk-你的OpenAI-Key
```

**Q: 我想离线使用（不用任何 API）？**
编辑 `.env`，切换到本地 embedding：
```
EMBEDDING_PROVIDER=local
EMBEDDING_MODEL=shibing624/text2vec-base-chinese
EMBEDDING_DEVICE=cpu
HF_ENDPOINT=https://hf-mirror.com
```
首次启动会自动下载约 400MB 的模型文件。
